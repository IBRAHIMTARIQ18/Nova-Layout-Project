# NovaLayout — Modern Agency Website Template

NovaLayout is a responsive agency-style website template built using HTML, CSS, and JavaScript.  
Designed with a modern UI approach, this project showcases a structured layout including a hero section, feature cards, navigation bar, and footer.

The goal of this project is to demonstrate clean layout architecture, reusable design sections, and interactive front-end effects suitable for agency or business websites.

---

## Features

- Responsive website layout
- Sticky glassmorphism navbar
- Several Animations
- Hero banner section
- Modern service cards
- Scroll reveal animations
- Interactive cursor glow effect
- Clean typography and spacing
- Gradient-based UI design
- Hover interactions and transitions

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
